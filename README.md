# 1. Créer le fichier README.md vide (ou utilisez votre éditeur de texte comme VS Code)
touch README.md

# 2. Après avoir écrit dedans (voir Étape 2), préparez le fichier
git add README.md

# 3. Enregistrez la modification
git commit -m "Ajout du fichier README"

# 4. Envoyez le fichier sur GitHub
git push
